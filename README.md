# Техэтаж

Telegram-бот с мини-приложением для техэтажа общаги: прачечная (стиралки, сушилки, очередь, брони) и календарь броней игровой. Работает на Cloudflare Workers, данные хранятся в D1.

Весь сервер находится в `src/worker.js`. Он принимает вебхук Telegram (`/telegram`), отдаёт страницу приложения (`webapp/index.html`) и обрабатывает её запросы (`/api/state`, `/api/action`). Пользователь проверяется по подписи Telegram. Cron раз в минуту вызывает `tick()`: напоминания, конец программ, брони, обновление закрепов. Таблицы в базе создаются сами, настройки лежат константами в начале файла.

Деплой: `npm install`, `npx wrangler login`, потом `npm run deploy`. Секреты `BOT_TOKEN` и `WEBHOOK_SECRET` задаются в Cloudflare, в репозиторий их не кладём. Тесты в `tests/` работают с фейковым Telegram: запустите `python tests/faketg.py` и `npm run test:server`, затем в папке `tests` запустите `drive.py`, `room.py` и `done.py`.
